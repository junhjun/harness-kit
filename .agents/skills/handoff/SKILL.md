1. HANDOFF.md를 덮어쓴다. SPEC, PLAN, LOG에 있는 내용은 경로만 적는다.
   - 지금 상태: 3줄 이하, PLAN 몇 단계까지 끝났나
   - 돌고 있는 작업: 띄운 서버와 백그라운드 명령(터미널, 포트, 다시 띄워야 하나). 없으면 "없음"
   - 기다리는 결정, 다음 할 일, 함정(3개 이하), 직전 설명. 없으면 "없음"
2. 커밋하지 않은 변경은 `wip: 인계`로 커밋한다.
3. 아래 두 줄만 출력하고 멈춘다.
   /new
   HANDOFF.md를 읽고, git log와 테스트로 상태를 확인한 뒤 지금 상태를 세 줄로 보고하고 멈춰.
